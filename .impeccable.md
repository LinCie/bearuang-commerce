## Design Context

### Users

Developers building e-commerce sites using the BearUang API. They need a clean, professional, accessible foundation they can customize with their own branding. Users expect WCAG-compliant, well-structured code and design.

### Brand Personality

**Minimal & Refined** — The design should be a pristine canvas, not a statement. Clean, functional, trustworthy. The opposite of decorative or opinionated — it should feel like a premium blank slate that elevates whatever content is placed on it.

### Aesthetic Direction

**Void of style, maximizing UX** — Think of it as the IKEA manual of commerce: nothing is decorative, everything is purposeful. Crisp typography, generous whitespace, WCAG AA+ contrast ratios, responsive and accessible by default. A developer looking at this template should think "I can build anything on top of this."

### Design Principles

1. **Zero decoration** — No gradients, no shadows as decoration, no visual flourishes. Only functional visual elements that serve a UX purpose.
2. **WCAG non-negotiable** — All interactions must meet WCAG AA at minimum; aim for AAA where possible.
3. **Typography carries the design** — With no decorative elements, typography does the heavy lifting. Choose fonts that are beautiful at rest, not just "clean."
4. **Template, not product** — The design should be easily customizable. Use CSS variables extensively so theming is straightforward.
5. **Light mode only** — Single theme reduces complexity for implementers.
